# HamoSinkFinder
The Chrome extension I made while learning a lot about XSS for finding XSS sinks and string decoding/parsing. I find it's sometimes useful, although match and replace rules do a better job if there's no CSP

# usage
With Chrome DevTools open, click the extension, then press Inject. Now your breakpoints will trigger

# installation 
download the extension, go chrome extention, enable developer mode, and locate the folder to add
